## 📖 Guidance

### Behaviour Questions
- How to communicate with non-technical persons?
    - The non-technical persons usually do not really care what the model or data-driven methodology is. Instead, they want to know what problem can be solved and what the result looks like
    - You may also need to explain the model or data-driven methodology in few sentences, because this can improve their confindence to apply this model or data-driven methodology


### Basic Data Analysis
- If the sales drop by 20%. how do you find the root cause?
    - clarity: verify metric defination is same or not. Make sure it is a real change
    - breakdown the metric: traffic, add to cart, checkout
    - segment: new vs return customer, different country customer
    - diagnose: Once I know where the drop is coming from, I’d check likely causes: stock availability, pricing or promotions, marketing and lead volume, changes in the sales process, seasonality, and competitor activity

### Statistics
- If you have 1,000 customer support tickets, and want to draw a sample to validate the ticket quality. How to determine the sample size?
    - Decide necessary input: Confidence level: usually 95%, Margin of error, can use 5%. Expected quality rate: if you have no prior, use p = 0.5.
    - Apply it to sample size formula
    - the sample should be randomly draw, instead of using the latest ones
